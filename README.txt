==================================================
 지원결과 폴더 정리 규칙
==================================================

이 폴더는 뷰어 페이지(보기.bat)가 그대로 읽어서 보여줍니다.
아래 규칙대로만 폴더/파일을 두면 페이지가 자동으로 갱신됩니다.
규칙에 어긋난 곳이 있으면 페이지 맨 위 노란 상자
"정리가 필요한 항목"에 어디가 틀렸는지 표시됩니다.


--------------------------------------------------
1. 보는 방법
--------------------------------------------------
- 보기.bat 을 더블클릭 → 브라우저가 열립니다.
- 검은 창(서버)이 켜져 있는 동안만 페이지가 동작합니다. 다 보면 창을 닫으세요.
- 폴더를 고친 뒤에는 페이지의 [새로고침] 버튼을 누르면 바로 반영됩니다.
- PDF/이미지는 브라우저에서, HWP 등은 한글 같은 기본 프로그램으로 열립니다.
- 필요 프로그램: Python 3.8 이상


--------------------------------------------------
2. 전체 구조
--------------------------------------------------
  지원결과/
    {단계 폴더}/
      {반기 폴더}/
        {지원 폴더}/
          정보.txt
          (자소서, 지원서, 공고문, 캡처 등 아무 파일)
          기타/        ← 개인정보·증빙 서류

  예)
  지원결과/2차면탈/26하/연구개발특구진흥재단_26하/정보.txt


--------------------------------------------------
3. 단계 폴더 (최상위 폴더)
--------------------------------------------------
  서탈      서류 불합격
  서합      서류 합격
  필탈      필기 불합격
  필합      필기 합격
  1차면탈   1차 면접 불합격
  1차면합   1차 면접 합격
  2차면탈   2차 면접 불합격
  2차면합   2차 면접 합격
  3차면탈   3차 면접 불합격   (필요할 때 만들기)
  3차면합   3차 면접 합격     (필요할 때 만들기)
  최종합격  최종 합격

- 위 이름 외의 폴더를 만들면 경고가 뜹니다. (띄어쓰기 없이 정확히)
- 없는 단계 폴더는 필요할 때 새로 만들면 됩니다.

[핵심 규칙] 같은 지원이 여러 단계 폴더에 있으면 "가장 뒤 단계"가 최종 결과입니다.
- 결과가 나오면 지원 폴더를 다음 단계 폴더로 복사(또는 이동)하세요.
- 이전 단계 폴더에 남겨둬도 되고 지워도 됩니다.
  남겨두면 그 단계 폴더에 있던 파일도 한 화면에 합쳐서 보여줍니다.
- 폴더 이름은 모든 단계에서 글자 하나까지 똑같아야 같은 지원으로 묶입니다.


--------------------------------------------------
4. 페이지에 보이는 결과
--------------------------------------------------
  가장 뒤 단계 폴더       → 페이지 표시
  서탈                    → 서탈
  서합                    → 필기미응시
  필탈                    → 필탈
  필합                    → 1차면접미응시
  1차면탈                 → 1차면탈
  1차면합                 → 2차면접미응시
  2차면탈                 → 2차면탈
  최종합격                → 최종합격

- "합" 폴더가 가장 뒤 단계면 다음 전형은 "미응시"로 보입니다.
  (아직 결과가 안 나온 전형도 같은 방식으로 "미응시"로 보입니다.)
- 필기가 없는 전형이면 정보.txt의 "전형:"에 적어 주세요. (6번 참고)
  예) 전형: 서류, 1차면접  → 서합이 마지막이면 "1차면접미응시"


--------------------------------------------------
5. 반기 폴더 / 지원 폴더 이름
--------------------------------------------------
[반기 폴더]  연도 뒤 2자리 + 상/하
  25하, 26상, 26하 ...

[지원 폴더]  기업명_반기   또는   기업명_반기_구분
  한국전력공사_26상
  한국도로공사_26상_전산
  한국교통안전공단_25하_제3차

- 기업명은 공식 정식 명칭으로 씁니다. 약칭 금지.
    O 근로복지공단, 한국자산관리공사, 대한무역투자진흥공사, 한전KDN
    X 근복, 캠코, 무투공(KOTRA), 한전kdn
- 반기는 폴더 이름과 상위 반기 폴더가 같아야 합니다.
    O 서탈/26하/한국주택금융공사_26하
    X 서탈/26상/한국주택금융공사_26하
- 같은 기업에 같은 반기에 두 번 이상 지원했다면 뒤에 "_구분"을 붙여 나눕니다.
  구분은 직무(_전산, _행정)나 공고 차수(_제3차) 등 알아보기 쉬운 걸로.
  구분을 안 붙이면 두 지원이 하나로 합쳐져 버립니다.
- 괄호, 공백은 쓰지 않는 걸 권장합니다.


--------------------------------------------------
6. 정보.txt
--------------------------------------------------
지원 폴더마다 하나. 같은 지원이 여러 단계에 있다면
"가장 뒤 단계" 폴더의 정보.txt 만 읽습니다. (옮길 때 같이 옮기세요)

[형식]  (콜론 ":" 뒤에 값을 씁니다. 모르면 비워두세요)

  기업: 한국전력공사
  직무: 사무(전산)
  전형: 서류, 필기, 1차면접, 2차면접
  가점: 120
  메모:
  여기부터 아래는 자유롭게 여러 줄로 씁니다.
  가점 계산, 면접 질문, 느낀 점 등

- 기업: 폴더 이름의 기업명과 같게.
- 직무: 자유. 비워두면 페이지에 "전산"으로 표시됩니다.
- 전형: 쉼표로 구분. 쓸 수 있는 값 → 서류, 필기, 1차면접, 2차면접, 3차면접
        (1차, 2차, 면접 도 인식) 비워두면 "서류, 필기, 1차면접, 2차면접"
- 가점: 서류 가점 총점 숫자. 자유 형식이지만 숫자만 쓰는 걸 권장.
- 메모: 반드시 마지막 줄 항목. "메모:" 아래는 전부 메모로 보입니다.
- 저장은 UTF-8 (메모장 기본값). 다른 인코딩이면 경고가 뜹니다.
- 페이지의 [정보.txt 편집] 버튼으로 바로 열 수 있습니다.
- 메모용 txt 를 따로 만들지 말고 정보.txt 메모에 모아 주세요.


--------------------------------------------------
7. 그 밖의 파일
--------------------------------------------------
- 자소서, 지원서, 공고문, 직무기술서, 결과 캡처 등은 파일 이름 자유.
  (이름에 "자소서/자기소개서", "지원서/이력서", "공고", "직무"가 들어가면
   목록 위쪽에 정렬됩니다.)
- 이미지(jpg, png 등)는 "결과 캡처·이미지"에 썸네일로 모입니다.
- 하위 폴더를 만들어도 됩니다. (예: pic/)
- 주민등록등본, 고용보험, 자격증 사본, 봉사확인서 같은 개인정보·증빙은
  지원 폴더 안 "기타/" 폴더에 넣어 주세요. 페이지에서 접힌 상태로 따로 보입니다.


--------------------------------------------------
8. 업데이트 예시
--------------------------------------------------
  ① 서류 제출
     아직 폴더를 만들지 않습니다. (서류 결과가 나오면 만듭니다)
  ② 서류 결과 발표 (합격/불합격)
     페이지의 [새 지원 추가] 버튼 → 반기, 서류 결과, 기업명 입력 → [만들기]
     → 서합(또는 서탈)/26하/한국철도공사_26하/정보.txt 가 자동으로 만들어지고
       그 폴더가 탐색기로 열립니다. 자소서, 지원서, 공고문, 캡처를 넣으세요.
     (직접 폴더를 만들어도 됩니다. 위 규칙만 지키면 똑같이 보입니다.)
  ③ 필기·면접 결과 발표
     페이지에서 그 지원을 선택 → [결과 업데이트] → 합격 / 불합격 선택
     → 폴더가 통째로 다음 단계 폴더로 "이동"됩니다. (예: 서합 → 필합)
       비게 된 반기 폴더는 자동으로 지워집니다.
     → 이어서 결과 캡처, 면접 준비 자료를 넣고 정보.txt 메모에 후기를 적으세요.
     - 마지막 전형에 합격하면 최종합격 폴더로 갑니다.
       (마지막 전형 = 정보.txt "전형:"의 마지막 항목, 비어 있으면 2차면접)
     - 이동이 안 되면 폴더 안 파일이 한글·PDF·탐색기에서 열려 있는지 확인하세요.
     - 잘못 눌렀다면 탐색기에서 폴더를 원래 단계 폴더로 다시 옮기면 됩니다.


--------------------------------------------------
9. 페이지가 무시하는 것
--------------------------------------------------
- 지원결과 폴더 바로 아래의 파일 (26상_지원결과.txt, 이 README.txt 등)
- 이름이 _ 또는 . 으로 시작하는 폴더 (_viewer = 뷰어 프로그램)
  → _viewer 폴더는 지우거나 옮기지 마세요.
