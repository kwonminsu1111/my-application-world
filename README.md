# my-application-world

취업 지원 기록(전형 결과, 자소서, 공고, 결과 캡처)을 폴더로 정리해 두면,
그 폴더를 그대로 읽어서 보여주는 **로컬 전용 뷰어**입니다.

- 기업별 전형 진행 단계(서류 → 필기 → 면접 → 최종)를 한눈에
- 서류·필기 합격률, 면접 진출 수 등 반기별 요약
- 자소서·공고·캡처를 클릭 한 번으로 열기 (PDF·이미지는 브라우저, HWP는 한글)
- **새 지원 추가** 버튼으로 규칙에 맞는 폴더와 `정보.txt` 자동 생성
- **결과 업데이트** 버튼으로 다음 단계 폴더로 자동 이동
- **필기 복기**: `필기복기/{지원 폴더명}_복기.txt` 등을 필기를 본 지원에 연결해서 바로 읽기
- 폴더 규칙에 어긋난 곳을 찾아서 알려줌
- 라이트 / 다크 모드

## 실행

Windows + Python 3.8 이상이 필요합니다. 추가 패키지는 없습니다.

1. 이 저장소 파일들을 지원 기록 폴더(예: `지원결과/`)에 둡니다.
2. `보기.bat`을 더블클릭하면 브라우저가 열립니다. (`http://127.0.0.1:8765`)
3. 검은 창이 켜져 있는 동안만 동작합니다. 다 보면 창을 닫으세요.

서버는 `127.0.0.1`에만 열리며, 뷰어가 있는 폴더 밖의 파일은 읽거나 열지 않습니다.

## 폴더 구조

```
지원결과/
  {단계}/            서탈, 서합, 필탈, 필합, 1차면탈, 1차면합, 2차면탈, 2차면합, 최종합격
    {반기}/          26상, 26하, ...
      {기업명}_{반기}[_{구분}]/
        정보.txt     기업 / 직무 / 전형 / 가점 / 메모
        (자소서, 공고, 캡처 등 아무 파일)
        기타/        개인정보·증빙 서류
  필기복기/          {지원 폴더명}_복기.txt / .pdf / .hwp ...
  _viewer/           뷰어 (serve.py, index.html)
  보기.bat
```

같은 지원이 여러 단계 폴더에 있으면 가장 뒤 단계가 최종 결과입니다.
자세한 규칙은 [README.txt](README.txt)를 보세요.

## 개인정보

실제 지원 기록(자소서, 이력서, 등본 등)은 `.gitignore`로 모두 제외되어 있어
이 저장소에는 뷰어 코드와 문서만 올라갑니다.
